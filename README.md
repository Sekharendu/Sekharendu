# Hi, I'm Sekharendu Dey 👋

---

I'm a software engineer from Kolkata who likes building the parts of a product that live behind the interface.

- Most of my recent work has involved **Node.js backends, LLM integrations, retrieval, streaming, and observability**.
- I built **[LocalCortex](https://github.com/Sekharendu/LocalCortex)**, a local RAG application for chatting with PDF, Word, and Markdown documents.
- I'm currently building **[StreamMind](https://github.com/Sekharendu/StreamMind)**, a TypeScript and Fastify backend with streaming, conversation history, retrieval, and multi-provider LLM fallback.
